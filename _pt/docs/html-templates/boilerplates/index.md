# Boilerplates

Não comece do zero: copie um boilerplate e você já tem um template funcionando, com servidor de desenvolvimento, dados simulados e um script de empacotamento de um comando só.

- <a href="https://github.com/dsplay/dsplay-templates/tree/main/boilerplates/javascript" target="_blank">Vanilla JS</a>
- <a href="https://github.com/dsplay/dsplay-templates/tree/main/boilerplates/jquery" target="_blank">jQuery</a>
- <a href="https://github.com/dsplay/dsplay-templates/tree/main/boilerplates/react" target="_blank">React</a>
- <a target="_blank">Vue</a> (em breve)
- <a target="_blank">Angular</a> (de jeito nenhum :P)

```sh
npx degit dsplay/dsplay-templates/boilerplates/javascript my-template # ou jquery, react
cd my-template
npm install
npm start
```
