# Sala de reunião

Usado pelo template [Meeting Room](https://github.com/dsplay/dsplay-templates/tree/main/templates/meeting-room).

```js
var dsplay_media = {
  // Todos os campos gerais também estão incluídos...

  // Específicos do Meeting Room
  eventName: 'Convenção DSPLAY 2023', // Nome do evento
  location: 'Cupertino, CA - USA', // Local do evento
  startDate: '2023-07-11T12:00:00.000Z', // Início do evento (ISO 8601)
  endDate: '2023-07-15T14:00', // Fim do evento (ISO 8601)
}
```
