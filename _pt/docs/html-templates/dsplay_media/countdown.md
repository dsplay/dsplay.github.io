# Contagem regressiva

Usado pelo template [Countdown](https://github.com/dsplay/dsplay-templates/tree/main/templates/countdown).

```js
var dsplay_media = {
  // Todos os campos gerais também estão incluídos...

  // Específicos do Countdown
  title: 'Contagem regressiva para o ano novo - 2027', // Texto exibido junto à contagem
  date: '2026-12-31T00:00', // Data e hora alvo (ISO 8601)
}
```
