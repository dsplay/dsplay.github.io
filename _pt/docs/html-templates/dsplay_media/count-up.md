# Contagem progressiva

Usado pelo template [Count Up](https://github.com/dsplay/dsplay-templates/tree/main/templates/count-up).

```js
var dsplay_media = {
  // Todos os campos gerais também estão incluídos...

  // Específicos do Count Up
  title: 'Contando os dias do ano - 2026', // Texto exibido junto ao contador
  date: '2026-01-01T00:00', // Data e hora de início da contagem (ISO 8601)
}
```
