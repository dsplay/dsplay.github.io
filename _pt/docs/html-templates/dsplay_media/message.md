# Mídia de mensagem

O player não adiciona campos próprios a uma mídia de mensagem. Todo campo preenchido na mídia é copiado para `dsplay_media` como está, sem validação, então os campos dependem do template:

- [Countdown](./countdown) and [Count Up](./count-up)
- [Wi-Fi](./wifi)
- [Meeting Room](./meeting-room)
- [Flight Information](./flight-information)
- [Building Directions](./building-directions)

Templates que não precisam de dados da mídia (relógios, calendário, alertas, tarifas de hotel, tábua de marés, voice AI etc.) recebem apenas os campos gerais.
