# DSPLAY for Developers

**A screen is just a web page, and the data behind it is just JSON.** DSPLAY lets you control both.

- **Customize any template.** Templates are plain HTML, CSS and JavaScript. Start from a boilerplate, change what you want, zip it and upload it.
- **Connect any data source.** A JSON service is an HTTP endpoint that returns JSON. Point a media at it and your template renders what it returns.

```
your data  →  JSON service  →  DSPLAY player  →  your template  →  the screen
```
