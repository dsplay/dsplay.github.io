# Boilerplates

Don't start from scratch: copy a boilerplate and you get a working template with a dev server, mock data and a one-command packaging script.

- <a href="https://github.com/dsplay/dsplay-templates/tree/main/boilerplates/javascript" target="_blank">Vanilla JS</a>
- <a href="https://github.com/dsplay/dsplay-templates/tree/main/boilerplates/jquery" target="_blank">jQuery</a>
- <a href="https://github.com/dsplay/dsplay-templates/tree/main/boilerplates/react" target="_blank">React</a>
- <a target="_blank">Vue</a> (coming soon)
- <a target="_blank">Angular</a> (no way :P)

```sh
npx degit dsplay/dsplay-templates/boilerplates/javascript my-template # or jquery, react
cd my-template
npm install
npm start
```
