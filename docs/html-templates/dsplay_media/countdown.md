# Countdown

Used by the [Countdown](https://github.com/dsplay/dsplay-templates/tree/main/templates/countdown) template.

```js
var dsplay_media = {
  // All general fields are also included...

  // Countdown specific
  title: 'Countdown to the new year - 2027', // Text shown with the countdown
  date: '2026-12-31T00:00', // Target date and time (ISO 8601)
}
```
