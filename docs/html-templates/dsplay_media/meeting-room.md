# Meeting Room

Used by the [Meeting Room](https://github.com/dsplay/dsplay-templates/tree/main/templates/meeting-room) template.

```js
var dsplay_media = {
  // All general fields are also included...

  // Meeting Room specific
  eventName: 'DSPLAY Convention 2023', // Event name
  location: 'Cupertino, CA - USA', // Event location
  startDate: '2023-07-11T12:00:00.000Z', // Event start (ISO 8601)
  endDate: '2023-07-15T14:00', // Event end (ISO 8601)
}
```
