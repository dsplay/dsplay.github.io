# Message Media

The player adds no fields of its own to a Message media. Every field filled in the media is copied, as is and without validation, to `dsplay_media`, so the fields depend on the template:

- [Countdown](./countdown) and [Count Up](./count-up)
- [Wi-Fi](./wifi)
- [Meeting Room](./meeting-room)
- [Flight Information](./flight-information)
- [Building Directions](./building-directions)

Templates that need no media data (clocks, calendar, alerts, hotel rates, tide sheet, voice AI, etc.) only get the general fields.
