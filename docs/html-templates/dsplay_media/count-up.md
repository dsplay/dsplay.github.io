# Count Up

Used by the [Count Up](https://github.com/dsplay/dsplay-templates/tree/main/templates/count-up) template.

```js
var dsplay_media = {
  // All general fields are also included...

  // Count Up specific
  title: 'Counting days of the year - 2026', // Text shown with the counter
  date: '2026-01-01T00:00', // Date and time to count from (ISO 8601)
}
```
